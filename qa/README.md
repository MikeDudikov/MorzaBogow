# Zakres danych QA

Raporty testów i macierze są dowodami dla ich konkretnych uruchomień i wymagań. Nie zmieniaj ich wstecz, aby zgadzały się z planem.

`scenario-design.json` i jego walidator sprawdzają strukturę istniejącego zestawu danych; nie implementują kampanii K01–K14. `economy-baseline.json` oraz model w `docs/economy-model/` nie są kompletną definicją aktualnego rulesetu runtime.

Migracja danych: P02 i zadania scenariuszy w [PLAN_WDROZENIA.md](../docs/PLAN_WDROZENIA.md). Reguły docelowe: [NOWY_PLAN_GRY.md](../docs/NOWY_PLAN_GRY.md). Plan nie upoważnia do przepisywania statusów na PASS bez wykonania właściwego testu.
