# Morza Bogów — kontrakt operacji

Miejsca i kampania: [MAPY_I_SCENARIUSZE.md](MAPY_I_SCENARIUSZE.md). Wykonawca: P10 w [PLAN_WDROZENIA.md](PLAN_WDROZENIA.md).

Każda operacja ma rok fikcyjnej akcji, typ reprezentacji geografii, źródła materialne i mitologiczne, stan początkowy, cele, porażkę, posiłki, budżety, unikalne obiekty i CarryPolicy. Sektory mityczne nie otrzymują fałszywej lokalizacji archeologicznej.

Cel zależy wyłącznie od działającej reguły. Utrata niezbędnego obiektu uruchamia odzysk, alternatywę albo wykrytą porażkę. Powtarzane stworzenia nie powtarzają nagrody. Przenoszone przedmioty są jawne przed zamknięciem misji. Zapis zachowuje fazę celu i ID rozliczenia.
